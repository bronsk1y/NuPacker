Features

Edit metadata as fields

Change project metadata without manual XML coding. Just select a tag in the visual tree to instantly edit its text value or attributes in simple input fields.

A tree built for packages

Browse project files and package tags side by side, in a tree that just makes sense.

Built-in code editor

Switch to a full editor with syntax highlighting whenever you want more control.

Pack and publish in one click

Run dotnet pack and push the result to NuGet without a terminal.

Light and dark themes

Switch the whole interface to match how you like to work.

Keyboard-first workflow

Open, save, and switch tabs with shortcuts that keep you in the flow.
