Overview

NuPacker takes a project file to a published NuGet package in four stages. This page shows where each stage happens and where to find the details.

The path of a package

  1. Open

    Load a .csproj or .nuspec file.

    Get started

  2. Edit

    Change metadata as fields or work in the code editor.

    Editor

  3. Build

    Pack the project into a .nupkg file.

    Build and publish

  4. Publish

    Send the package to nuget.org.

    Build and publish

Finding your way around

The main window has four areas.

1Menu and toolbar
2Editor

4Output
  1. Menu and toolbar hold the file, edit, build and publish actions. Interface
  2. Editor shows every opened file on its own tab. Editor
  3. File tree lists the project and its files. Interface
  4. Output shows messages from building and publishing. Interface

Quick answers

  • How do I change the package version? Open the .csproj file, select the Version tag and edit its value. Editor
  • Where does the built package go? Into the bin folder of the project, inside the folder named after the selected configuration. Build and publish
  • Why does publishing fail? The most common reason is a missing API key. Enter it in Settings > NuGet. Settings
  • Can I build a .nuspec project? Not yet. A .nuspec file can be opened and edited, but building is available for .csproj projects. Build and publish
  • What do I need before installing? See the requirements in Get started.

Get started with NuPacker

This section explains how to install NuPack and what the requirements are.

Pre-installation Requirements

  1. The computer must have Windows 10 or higher installed.
  2. The NuGet command-line utility must be installed to upload package files. If it is not available, you can install it here.

Installing NuPacker

  1. Download the installer file.
  2. Run the installer and follow the instructions.
  3. Open NuPack and configure it if necessary.

Opening Files

NuPack works with .nuspec and .csproj project files. To open a file, follow the steps below:

  1. Open NuPacker and click on the File > Open File tab.
  2. Select your project file.

Once successfully loaded, a tree file will appear on the right.

Editor

NuPacker opens project files in one of two views, depending on the file and what you're editing.

Code Editor

Files like .cs and .txt open in a full code editor with syntax highlighting and line numbers.

  • Syntax highlighting for C# and plain text files.
  • Undo and redo across the entire editing session.
  • Cut, copy and paste, available from the menu or the keyboard.
  • Changes are marked with an asterisk (*) next to the file name until saved.

Simplified Editor

Project files like .csproj and .nuspec open in a simplified view instead of raw XML.

  1. Tags are shown as a tree. Tags with nested tags can be expanded, tags without them show their value directly.
  2. Click a tag to see its value and attributes on the right, and edit them as plain fields.
  3. Press Save to write the changes back to the file.

You can switch between the simplified view and the raw code editor at any time using the Use Simplified Editor / Use Normal Editor toggle.

Saving

  • Save writes changes to the current file.
  • Save As lets you choose a new location and name.

Keyboard Shortcuts

Save Ctrl + S

Interface

This section describes the toolbar, the file tree and the output panel.

Toolbar

  • Undo and Redo revert or restore changes in the code editor.
  • Open selects a project file.
  • Save writes the current file to disk.
  • Run builds the package.
  • Stop cancels a running build or publish.
  • Publish sends the built package to NuGet.

File Tree

The project file is the root of the tree. Expand it to see the folders and files next to it.

  • Double-click a file to open it in a new tab.
  • Use the arrow next to a folder to expand or collapse it.
  • Type in the search field to filter by name. Folders that contain a match stay visible.
  • Only .cs and .txt files are listed. The bin, obj and .git folders are hidden.

Output Panel

The panel shows the output of the build and publish commands. Colors indicate the type of message:

  • Black for regular messages.
  • Yellow for warnings.
  • Red for errors.
  • Green for success messages.

Build and publish

Building a Package

  1. Open your .csproj file.
  2. Optionally choose the configuration in Settings > Build.
  3. Click Run on the toolbar.
  4. Follow the progress in the output panel.

Use Stop to cancel a build in progress. Building is currently available for .csproj projects. .nuspec files can be opened and edited.

Publishing

  1. Enter your API key in Settings > NuGet.
  2. Build the package.
  3. Click Publish on the toolbar.

NuPacker sends the most recent .nupkg file from the bin folder of the selected configuration to nuget.org. The API key is not written to the settings file.

Settings

Open Edit > Settings, change the options and click Save to apply them.

General

  • Language: English or Русский.
  • Theme: System, Light or Dark.
  • Font Size: size of the interface text.

Editor

  • Editor Font and Editor Font Size for the code editor.
  • Tab Size and Indent Unit control indentation.
  • Line Numbers shows or hides the line number column.

Build

  • Configuration: Debug or Release.
  • Extra pack arguments are appended to the pack command.
  • Clean before build cleans the project before packing.

NuGet

  • API Key is used to publish packages.
  • Include symbols also builds and publishes a symbols package.
